# 规则与 TOML 配置

章节识别按行进行。每个正则只匹配一行源文本；匹配前会去掉行首行尾空白和
简单的标题装饰，正则不会看到整篇文档。

先从内置预设开始，再叠加 TOML 覆盖：

```bash
txt2epub inspect book.txt --profile auto --rules my-rules.toml
```

应用顺序是：

1. 内置预设（默认 `auto`）。
2. `--rules` 指定的 TOML 文件。
3. 命令行的 `--max-heading-length`。

未知的 TOML 键和无效正则会报规则/配置错误（退出码 `3`），不会抛出
traceback。规则文件按 UTF-8 读取，允许带 BOM。

## 内置预设

| 预设 | 行为 |
| --- | --- |
| `auto`（默认） | 常见网文格式，允许带缩进的标题。 |
| `strict` | 只接受顶格标题，要求数字与标题之间有分隔符，长度上限 40。 |
| `loose` | 允许缩进标题、更长的标题和纯数字标题。 |

针对特定站点的清理不内置为预设。请把这些模式写进本地规则文件；参见下面的
知轩藏书示例。

## TOML 参考

### `[heading]`

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `max_length` | 整数 | `50` | 标题长度上限。`strict` 为 `40`，`loose` 为 `80`。 |
| `allow_indented_headings` | 布尔 | `true` | 接受以 U+3000、空格或制表符缩进的标题。`strict` 设为 `false`。 |
| `pure_number_headings` | 布尔 | `false` | 识别 `1. 标题` 这类纯数字标题。`loose` 会启用。 |
| `volume_suffix_special_suffixes` | 字符串列表 | `["序", "章", "篇", "传", "记", "录"]` | 可以把合写卷名拆成特殊章节的后缀，例如 `第一卷 卷名 卷首序`。 |

### `[patterns]`

每个模式键是一个正则字符串或字符串列表。正则通过 `re.match` 应用，因此
建议用 `^` 锚定开头，并通常用 `$` 锚定结尾。

| 键 | 命名分组 | 说明 |
| --- | --- | --- |
| `volume` | `num`、`title` | 卷标题，例如 `第一卷 卷名`。 |
| `chapter` | `num`、`title`，可选 `num2` | 章标题。合章标题（如 `第1037章—第1038章`）使用 `num2`。 |
| `section` | `num`、`title` | 节标题，例如 `第1节 标题`。 |
| `combined` | `volume`、`vnum`、`chapter`、`cnum` | 同一行内的卷 + 章标题。章标题从 `chapter` 中解析。 |
| `special` | `title` 或 `special` | 特殊章节。两个分组都没有时，整行作为标题。 |
| `replace_patterns` | 布尔 | 为 `true` 时，提供的每个模式键会替换对应的内置列表，而不是追加。 |

默认情况下，自定义模式会追加到内置列表。命名分组不是匹配成功的必要条件，
但解析器会用它们生成序号、目录标题、缺口检测和去重信息。建议使用上表中的
名称。

### `[exclude]`

这些列表用于避免误判。默认追加到内置列表。

| 键 | 说明 |
| --- | --- |
| `volume_suffixes` | 卷单位后出现这些文字时，说明该行是正文。例如 `第三部门…` 不是 `第三部`。 |
| `chapter_suffixes` | `回` 后出现这些文字时，说明该行是正文。例如 `第一回合…` 不是第一章。 |
| `replace_exclude` | 为 `true` 时，提供的后缀列表替换内置列表，而不是追加。 |

### `[noise]`

| 键 | 说明 |
| --- | --- |
| `patterns` | 一个正则字符串或字符串列表。噪声模式使用 `re.search`，可以匹配短行中的任意位置。 |
| `replace` | 为 `true` 时替换内置噪声列表，而不是追加。 |

噪声清理只作用于短行（80 个字符以内）。被删除的行会记录在逐行台账中，
并计入丢弃文本，因此覆盖率仍然平衡。`--keep-noise` 会把它们保留为正文
段落。

## 示例

示例为简洁起见只使用 `[0-9]`。内置数字字符类还覆盖全角数字、中文数字、
大写数字、廿/卅 和罗马数字：
`0-9０-９零〇一二三四五六七八九十百千万两壹贰叁肆伍陆柒捌玖拾佰仟廿卅IVXLCDMivxlcdm`。

### 标准卷章结构

```text
第一卷 占位卷名
第1章 占位标题
```

`auto` 预设可以直接处理，不需要规则文件。

### 数字与标题之间没有分隔符

```text
第一章占位标题
```

`auto` 和 `loose` 已经支持。`strict` 要求分隔符。如果仍想使用 `strict`
预设，同时接受无分隔符的章标题：

```toml
[patterns]
chapter = '^第(?P<num>[0-9零〇一二三四五六七八九十百千万两]+)[章节回集幕](?P<title>.+)$'
```

默认情况下模式是追加的，因此这会增加一个后备规则，而不会丢弃 `strict`
的原有规则。

### 其他章节单位，例如「话」

```text
第12话 占位标题
```

```toml
[patterns]
chapter = '^第(?P<num>[0-9零〇一二三四五六七八九十百千万两]+)话\s*(?P<title>.*)$'
```

`\s` 可以匹配普通空格和全角空格 U+3000。

### 带缩进的标题

```text
　　第一章 占位标题
```

`auto` 和 `loose` 预设接受缩进标题。如果要关闭：

```toml
[heading]
allow_indented_headings = false
```

缩进卷名还有额外限制：长度必须不超过 20 个字符，并且后面要紧跟章节。
看起来像普通句子的缩进特殊章节会保留为正文。

### 卷名和章名在同一行

```text
第一卷 占位卷名 第1章 占位章名
```

`auto` 预设会把它拆成卷节点和嵌套的章节点。要支持其他单位，可以添加
combined 模式：

```toml
[patterns]
combined = '^(?P<volume>第(?P<vnum>[0-9]+)篇.*?)[\s　:：]+(?P<chapter>第(?P<cnum>[0-9]+)回.*)$'
```

同一行源文本会变成两级目录：`volume` 生成卷，`chapter` 生成章。

### 纯数字标题

```text
1. 占位标题
001、序
```

```toml
[heading]
pure_number_headings = true
```

内置纯数字模式接受 `1. 标题` 和 `001、序`。如果分隔符不同，可以改用
章模式：

```toml
[patterns]
chapter = '^(?P<num>[0-9]+)[）)]\s*(?P<title>.+)$'
```

### 自定义特殊章节

```text
卷首语
设定集
```

```toml
[patterns]
special = [
  '^(?P<special>卷首语)$',
  '^(?P<title>设定集.*)$',
]
```

### 站点噪声与误判

```toml
[noise]
patterns = ["免费阅读", "最新网址", "请收藏本站"]

[exclude]
volume_suffixes = ["门", "队"]
chapter_suffixes = ["回廊"]
```

### 特定站点噪声

针对特定站点的清理应放在本地规则文件中，而不是内置预设。例如知轩藏书风格
的页面可以使用：

```toml
[noise]
patterns = ["知轩藏书", "更多精校小说", 'zxcs\.me']
```

可以保存为 `zxs.toml`，然后通过 `--rules zxs.toml` 使用。这些模式会追加到
内置噪声列表。如果只想保留这些模式，可以在 `[noise]` 中加上
`replace = true`。

### 替换而不是追加内置规则

```toml
[patterns]
replace_patterns = true
chapter = '^第(?P<num>[0-9]+)话\s*(?P<title>.*)$'
```

这会替换内置的章模式，但不会改动内置的卷、节、combined 和特殊章节模式。
